# eapbuild

**Orçamento de obra com IA.** Envie as pranchas do projeto (PDF, DXF ou IFC) e receba a EAP por disciplina, com quantitativos, preços e as pendências sinalizadas para revisão. Exporte em PDF e planilha e mande ao cliente um link só com o preço final.

- Site: [eapbuild.com.br](https://eapbuild.com.br)
- Veja um orçamento de exemplo: [eapbuild.com.br/exemplo](https://eapbuild.com.br/exemplo)

## No seu assistente de IA

Use o eapbuild direto do Claude, ChatGPT/Codex, Cursor, VS Code e OMP pelo servidor MCP `https://eapbuild.com.br/api/v1/mcp`.

- Plugin do Claude Code e configuração: [eapbuild/mcp](https://github.com/eapbuild/mcp)
  ```
  /plugin marketplace add eapbuild/mcp
  /plugin install eapbuild@mcp
  ```
- Passo a passo por ferramenta: [eapbuild.com.br/integracoes](https://eapbuild.com.br/integracoes)
- Registro oficial de MCP: `br.com.eapbuild/eapbuild`
